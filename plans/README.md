# Aozora Cat Implementation Plans

Generated by the `improve` skill on 2026-08-27. The repository had no commits
or source files when these plans were written; `main` was unborn. Execute the
plans in the order below unless the dependency column allows parallel work.

## Agreed product constraints

- Mobile-first public PWA for iPhone Safari and Android Chrome.
- SvelteKit + TypeScript on Cloudflare Workers Static Assets.
- Vertical paged reading by default; horizontal writing is optional.
- No account, ads, payment, social features, or server-side reading history.
- Copyright-expired Aozora Bunko works only; preserve source attribution.
- Weekly reviewed import; strict sanitization; failed conversions do not ship.
- Opened works and the catalog remain usable offline.
- AGPL-3.0 source license.

| Command | Expected result |

## Decisions explicitly deferred beyond the beta

- Accounts and device synchronization.
- Notes, highlights, comments, reviews, social features, and rankings.
- Text-to-speech, AI summaries/explanations, full-text search, and file import.
- Paid services, advertising, and tablet/desktop-specific layouts.
- Custom domain migration; beta starts on the free Cloudflare subdomain.

## Findings considered and rejected

- Putting generated corpus data in Git: rejected because it creates large,
  noisy diffs and does not guarantee reviewed input provenance.
- Fetching Aozora Bunko at reading time: rejected because offline behavior,
  stable rendering, and upstream load would be worse.
- Rendering upstream XHTML directly: rejected because it violates the strict
  sanitization boundary and cannot guarantee a stable reader DOM.
- Shipping copyright-active works: rejected because the public redistribution
  boundary must remain unambiguous.
