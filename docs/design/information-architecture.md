# Aozora Cat 情報設計

Plan 002 の画面と状態を、後続のUI実装が参照する契約としてまとめる。
Aozora Cat はログインなし・広告なし・端末内保存のみとし、読書中の静けさを優先する。

## 画面とURL

| 画面               | URLの形                        | 主な役割                                                   | 常設ナビゲーション                             |
| ------------------ | ------------------------------ | ---------------------------------------------------------- | ---------------------------------------------- |
| ホーム             | `/`                            | 検索、読みかけ、季節の特集、初心者向け作品を入口にする     | ホーム / 本棚 / その他                         |
| 検索モード         | `/?mode=search`                | ホーム上の検索バーを展開して作品を探す                     | ホーム / 本棚 / その他（検索中はホームが戻る） |
| 現在の季節特集     | `/features/current`            | 今季の特集説明と対象作品をまとめて見る                     | ホーム / 本棚 / その他                         |
| 特集アーカイブ     | `/features/archive`            | 期限切れの特集を一覧する                                   | ホーム / 本棚 / その他                         |
| 特集アーカイブ詳細 | `/features/archive/:featureId` | 過去の特集と対象作品を確認する                             | ホーム / 本棚 / その他                         |
| 作品情報           | `/works/:workId`               | 作品名、著者、読み、状態、底本・入力者・校正者を確認する   | ホーム / 本棚 / その他                         |
| 読書               | `/works/:workId#read`          | 作品本文と挿絵をページ送りで読む                           | なし。中央タップ時だけ操作バー                 |
| 本棚               | `/bookshelf`                   | 読書中・お気に入り・読了をタブで管理する                   | ホーム / 本棚 / その他                         |
| その他・設定       | `/other`                       | 表示設定、保存容量、プライバシー、フィードバックを確認する | ホーム / 本棚 / その他                         |

検索は独立したトップレベルのタブにしない。ホームの検索バーを押すと同じ画面が検索モードへ切り替わり、閉じる操作でホームへ戻る。

作品情報と読書は同じ `/works/:workId` ルートを共有し、`#read` が付いたときだけ読書モードへ切り替える。これにより作品情報のURLを保ったまま読書を共有でき、読書位置などの端末内状態をURLへ含めない。

本棚の補助画面は `/bookshelf/history`（履歴）と `/bookshelf/offline`（オフライン）とする。これらはトップレベルの下部ナビゲーション項目ではなく、本棚から開く画面にする。

## ナビゲーション規則

- 下部ナビゲーションの本体は高さ `64px` 以上とし、占有高には `env(safe-area-inset-bottom)` を加える。各項目のタップ領域は `44px` 以上にする。
- 読書画面では下部ナビゲーションを描画しない。本文以外の操作は中央タップで開く一時バーに集約する。
- 戻る操作はブラウザ履歴と画面内の戻るボタンを同じ意味にする。
- 作品カード全体を作品情報へのリンクにし、カード内に別の小さなリンクを重ねない。
- 猫の印はホーム・本棚・その他にだけ置き、本文ページの視界には置かない。

## 画面ごとの状態

### ホーム

- **通常**: 検索バー、読みかけ、季節の固定特集、初心者向け作品をこの順で並べる。
- **初回**: 画面中央に一度だけ「読み方」オーバーレイを表示する。閉じても本文の入口は隠さない。
- **読み込み中**: 特集とカードの位置を保った骨格だけを表示し、スピナーを使わない。
- **空**: おすすめが空の場合は「作品を探す」検索バーを主行動として表示する。
- **オフライン**: 端末にある最近の作品と本棚は表示し、「保存済みの作品を読めます」と知らせる。
- **エラー**: カタログ取得の失敗理由と再試行を表示する。保存済みの本棚は隠さない。

### 季節特集

- **現在**: `/features/current` で特集名・紹介文・対象作品を表示し、作品カードから作品情報へ進める。「過去の特集を見る」からアーカイブを開く。
- **アーカイブ**: `/features/archive` で期限切れの特集を新しい順に一覧し、項目を押すと `/features/archive/:featureId` の詳細へ進む。
- **詳細**: 特集の紹介と対象作品を表示し、ブラウザの戻る／画面内の戻るで直前の特集一覧またはホームのスクロール位置へ戻る。
- **該当なし**: 現在の特集がない場合はホームの季節特集を表示せず、恒常的な初心者向けおすすめへフォールバックする。アーカイブが空の場合は「過去の特集はありません」と表示する。

### 検索モード

- **通常**: 入力欄に自動フォーカスし、作品名・著者名・双方の読み・副題を対象にする。
- **入力中**: 入力文字を保持したまま結果を更新する。検索語はURLやサーバーリクエストに含めず、クライアント状態（必要なら History API の state）だけに保持する。
- **空**: 「作品名や著者名で探す」という例示だけを表示する。
- **該当なし**: 検索語を残し、「見つかりませんでした。別の語で試す」を表示する。
- **オフライン**: 端末に保存済みの作品だけを検索対象にし、その範囲を明記する。
- **エラー**: 検索できない理由と再試行を表示し、入力文字を失わない。

### 作品情報

- **通常**: 作品の基本情報、状態操作、読書開始／再開、保存状態、出典情報を分けて表示する。
- **保存中**: 本文と挿絵の保存進捗を表示し、読書開始は可能にする。失敗時は再試行できる。
- **オフライン**: 保存済みなら「オフラインで読めます」、未保存なら「接続時に保存できます」と表示する。
- **作品削除**: 通常のカタログ整理と権利変更による削除を区別して理由を説明する tombstone を表示する。通常の整理では保存済み本文の再開を許可し、権利変更の場合は読書開始／再開を表示しない。
- **エラー**: 作品を取得できない場合は出典へのリンクとホームへ戻る操作を示す。

### 読書

- **通常**: 本文だけを表示する。縦書きを標準とし、左右端のジェスチャー領域でページを送る。
- **初回**: 最初の入場時だけ、左右のページ送りと中央タップを説明するオーバーレイを表示する。
- **オフライン**: 保存済み本文と挿絵をそのまま読める。未保存の画像は欠落箇所を本文上に重ねない。権利変更で無効化された作品本文は読めない。
- **保存容量不足**: 次回保存を止め、設定の保存管理へ誘導する。読書中の本文は継続する。
- **最終ページ**: 到達時に読了状態を端末内へ保存する。作品情報から未読・読書中・読了を手動変更できる。
- **エラー**: ページを描画できない場合は作品情報へ戻る操作と再試行を一時バーに置く。

### 本棚

- **通常**: 「読書中」「お気に入り」「読了」をタブで切り替え、「履歴」「オフライン」は補助画面として開く。
- **空**: 各区画に一文の説明と、ホームへ戻る／作品を探す操作を置く。
- **オフライン**: すべて端末内データで表示できる。同期を想起させる文言やアカウント導線を置かない。
- **作品削除**: カタログから消えた作品はカードを tombstone 化し、作品名・著者・削除理由を残す。通常の整理では保存済み本文を読めるが、権利変更の場合は本文をキャッシュから無効化し、読む操作を残さない。
- **ストレージ不足**: 保存済み作品の管理画面への導線を上部に固定するが、読書カードを覆わない。

### その他・設定

- **通常**: 文字サイズ、背景テーマ、縦書き／横書き、保存容量、プライバシー、出典、フィードバックを並べる。
- **設定変更中**: 変更は即時反映し、画面を閉じても端末内へ保存する。リセットは明示確認を行う。
- **オフライン**: 表示設定と保存管理は利用できる。フィードバックだけ接続時に送る案内を出す。
- **エラー**: 保存操作に失敗した場合は理由と再試行を同じ行に置く。

## 主要な遷移

1. ホームの検索バーを押す → 検索モード（入力欄へフォーカス）
2. ホームの季節特集カードを押す → `/features/current`（戻るとホームのスクロール位置へ戻る）
3. 現在の特集の「過去の特集を見る」を押す → `/features/archive`
4. 特集アーカイブの項目を押す → `/features/archive/:featureId`（戻るとアーカイブの位置へ戻る）
5. 検索結果または特集の作品を押す → 作品情報
6. 作品情報の「読み始める／続きを読む」を押す → `/works/:workId#read` の読書モード（保存済みなら即時表示）
7. 読書の中央タップ → 上下の操作バーを開閉（操作後、数秒で自動的に隠す）
8. 読書の左スワイプ／左端タップ → 次ページ、右操作 → 前ページ
9. 作品情報の状態操作 → 未読／読書中／読了を端末内へ保存
10. 下部ナビゲーションの本棚 → 本棚、履歴／オフライン → 補助画面、その他 → その他・設定
11. ブラウザの戻る／画面内の戻る → 直前の画面へ戻る。読書から戻る際は位置を保存する

## 保存するローカル状態

保存対象は同じブラウザ・端末のローカルストレージまたはIndexedDBだけに置く。外部へ送信しない。

- 作品ごとの段落IDと段落内の文字位置
- 読書履歴、お気に入り、読了状態
- 文字サイズ、背景テーマ、縦書き／横書き
- 本文・挿絵のオフライン保存状態
