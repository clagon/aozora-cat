# Aozora Cat モバイルワイヤーフレーム

実装前に画面の優先順位と操作領域を固定するための、アクセシブルなテキストワイヤーフレーム。寸法は CSS ピクセルで、対象は 390 × 844 と 360 × 800。図中の `[n]` はキーボードフォーカス順、`⌘` はタップ可能な領域を示す。

## 共通ルール

- 端末の左右 16px を安全余白にする。下部ナビゲーションは 64px、高さ 44px 未満の操作は作らない。
- 本文ページの左右 20% は前後ページのタップ領域、中央 60% は本文領域。本文の上に操作要素を重ねない。
- 画面幅が 360px の場合も、カード内の本文は 16px 以上、操作ラベルは 14px 以上を保つ。
- `[1]` から `[n]` の順に Tab 移動し、画面外の要素へフォーカスを送らない。読書画面は本文 → 操作バーの順にする。
- スワイプを使えない利用者向けに、同じ動作をする端タップボタンとラベルを用意する。

## 4. 読書（縦書き標準）

図中の「前ページ／次ページ」はタップ領域の説明用ラベルで、実画面には描画しない。実装では左右端の透明な領域と、支援技術向けの代替ボタンで同じ操作を提供する。

### 390 × 844

```text
┌──────────────────────────────┐
│  [1]⌘次ページ ← 20% → [2]⌘前ページ│  ← 操作の意味を兼ねる端タップ
│ ┌─────┐ ┌─────┐ ┌─────┐       │
│ │ 先  │ │  本  │ │  文  │       │  ← 中央 60% が本文
│ │  生  │ │  の  │ │  を  │       │
│ │  は  │ │  中  │ │  読  │       │
│ │  静  │ │  に  │ │  む  │       │
│ │  か  │ │  読  │ │  。  │       │
│ └─────┘ └─────┘ └─────┘       │
│                              │
│     [3]⌘操作バー（中央タップ）  │  ← 上下の一時バーを開閉
└──────────────────────────────┘
```

### 360 × 800

```text
┌────────────────────────┐
│ [1]⌘次ページ ←  → [2]⌘前ページ│
│ ┌────┐ ┌────┐ ┌────┐   │
│ │先  │ │本  │ │文  │   │
│ │生  │ │の  │ │を  │   │
│ │は  │ │中  │ │読  │   │
│ │静  │ │に  │ │む  │   │
│ │か  │ │読  │ │。  │   │
│ └────┘ └────┘ └────┘   │
│                        │
│  [3]⌘操作バー（中央タップ）│
└────────────────────────┘
```

キーボード順は、[1] 次ページ（左端タップの代替）、[2] 前ページ（右端タップの代替）、[3] 操作バー表示（中央タップの代替）。実装では3つを `button` として本文の後に並べ、ジェスチャーと同じ動作を支援技術へ公開する。

操作バーを開いた場合だけ、上部に作品名・ページ位置、下部に「作品情報」「表示設定」「本棚へ戻る」を表示する。操作後は数秒で自動的に隠す。本文上に常設ボタンや猫の装飾を置かない。

## 必須のエッジ状態

### 初回の読み方オーバーレイ（ホームまたは読書への初回入場）

```text
┌──────────────────────┐
│      読み方           │
│ 左端タップ：次ページ  │
│ 右端タップ：前ページ  │
│ 中央タップ：操作を表示│
│                      │
│ [1]⌘閉じる            │
└──────────────────────┘
```

オーバーレイは本文を完全に覆わず、背景を暗くしてもコントラストを保つ。`Esc` と閉じるボタンの両方で閉じられる。

### 作品削除 tombstone（通常のカタログ整理）

```text
┌────────────────────────┐
│ 公開カタログから削除   │
│ こころ                 │
│ 現在のカタログには      │
│ 掲載されていません。    │
│ 端末に保存済みの本文は │
│ そのまま読めます。     │
│ [1]⌘保存済みを読む     │
│ [2]⌘本棚から外す       │
└────────────────────────┘
```

### 作品削除 tombstone（上流の権利変更）

```text
┌────────────────────────┐
│ 権利上の理由で配信停止 │
│ こころ                 │
│ この作品の本文は端末に │
│ 保存済みでも読めません。│
│ [1]⌘出典を確認         │
│ [2]⌘本棚から外す       │
└────────────────────────┘
```

権利変更の tombstone には本文を開く操作を置かず、作品名・著者・状態・公式出典カードだけを残す。

### 保存容量不足 notice

```text
┌────────────────────────┐
│ 保存容量がいっぱいです │
│ 新しい作品を保存する前に│
│ その他 > 保存 から不要な│
│ 作品を整理してください。│
│                        │
│ [1]⌘保存を管理  [2]⌘閉じる│
└────────────────────────┘
```

読書中に表示する場合は一時バーの下から出し、本文の文字列やページ送り領域を覆わない。

### オフライン状態

```text
┌────────────────────────┐
│ オフライン             │
│ 保存済みの作品を読めます│
│ カタログの更新は接続時に│
│ 自動で行います。        │
│ [1]⌘保存済みを開く      │
└────────────────────────┘
```

接続がないことだけを知らせ、ログインや同期を促す表現は使わない。
