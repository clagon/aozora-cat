# Aozora Cat デザイントークン契約

`src/lib/ui/tokens.css` は値だけを定義する共有契約で、画面やコンポーネントのセレクターは持たない。後続のUI実装はこの変数を参照し、画面ごとに色や余白を再発明しない。

## 視覚の方針

- **紙の余白**: 本文は明朝系、背景は無漂白紙の色を標準にする。
- **静かな青**: リンクとフォーカスだけに濃い青を使い、操作の所在を知らせる。
- **猫の印**: ブランドの小さな猫は探索画面だけに置き、読書面には置かない。
- **重ねない本文**: 読書の本文領域へ常設コントロールを重ねない。

### コントラスト確認（WCAG 2.2 AA）

通常文字は 4.5:1 以上、大きな文字は 3:1 以上を基準にする。以下は相対輝度から算出した代表的な組み合わせで、補助情報を含めて通常文字の基準を満たす。

| テーマ | 本文 / 背景 | 補助情報 / 背景 | リンク / 背景 | 本文 / 面 |
| ------ | ----------: | --------------: | ------------: | --------: |
| 紙     |     12.29:1 |          5.80:1 |        7.23:1 |   13.41:1 |
| 白     |     14.35:1 |          6.77:1 |        8.44:1 |   13.51:1 |
| 夜間   |     14.56:1 |          9.94:1 |       11.65:1 |   12.58:1 |

境界線は文章ではなく区切り・フォーカスの補助に使う。フォーカスリングは `outline: var(--focus-ring-width) var(--focus-ring-style) var(--color-focus)` のように合成し、3px 以上で背景とのコントラストを確保する。

## 書体と文字サイズ

| 用途 | トークン                | 値・契約                                       |
| ---- | ----------------------- | ---------------------------------------------- |
| 本文 | `--font-reading`        | `ui-serif` を先頭にしたシステム明朝            |
| UI   | `--font-ui`             | `ui-sans-serif` を先頭にしたシステムサンセリフ |
| 小   | `--text-reading-small`  | 16px、補助的な本文                             |
| 標準 | `--text-reading-medium` | 18px、初期値                                   |
| 大   | `--text-reading-large`  | 20px                                           |
| 特大 | `--text-reading-xlarge` | 24px                                           |

本文は `--text-reading-line-height: 2` を基準にし、ユーザーが選んだ文字サイズだけを変えて行間を詰めない。UIラベルは 14px 以上、本文は 16px 以上とする。

## 余白・操作領域

- 基本の画面余白は `--content-gutter: 16px`。390pxと360pxの両方で同じ階層を保つ。
- `--tap-target-min: 44px` をすべてのボタン、リンク、ナビ項目の最小幅・最小高にする。
- 下部ナビゲーションは `--bottom-nav-height: 64px`。読書画面には置かない。
- 読書画面の左右 `--reader-edge-zone: 20%` は次／前ページのタップ領域、中央 `--reader-text-zone: 60%` は本文領域とする。
- 角丸・影は控えめにし、カードの区切りは余白と `--color-border` を優先する。

## フォーカス・動き

- キーボードフォーカスは `--focus-ring-width`、`--focus-ring-style`、`--color-focus` を合成し、`--focus-ring-offset` を加える。色だけで状態を伝えない。
- 標準の状態変化は `--motion-duration-standard`。ページ送りのアニメーションは短く、読書位置を見失わせない。
- `prefers-reduced-motion: reduce` のときはCSS変数を 1ms に上書きし、スクロールや変形を必須にしない。
- 初回オーバーレイは `Esc` で閉じられ、閉じた後に元の操作へフォーカスを戻す。

## テーマ切替

ルート要素の `data-theme` に `white`、`paper`、`night` のいずれかを設定する。未指定時は紙テーマを使う。テーマ名は「白」「紙」「夜間用」と表示し、設定変更は端末内へ保存する。

## 後続実装への禁止事項

- 読書画面へ猫の装飾、下部ナビ、広告、ログイン導線を追加しない。
- 検索をトップレベルの第4タブにしない。検索はホームのモード切替として実装する。
- 本文を未検証の外部HTMLとして直接挿入しない。
- サーバーへ読書履歴・お気に入り・表示設定を送信しない。
